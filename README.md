# wallpaper-collection

A personal collection of wallpapers I gather for everyday use. It'll keep growing, so check back once in a while.

## What's inside

| Folder | Contents |
| --- | --- |
| `sketch-walls/` | Black-and-white lineart sketches, simple and clean |

More folders will show up as the collection grows.

## How to use

Clone the repo:

```bash
git clone https://github.com/<username>/wallpaper-collection.git
```

Or just browse the folders on GitHub, click an image you like, and download it.

## Credits

All wallpapers here are **not my own work**. Most of them come from [Wallhaven](https://wallhaven.cc), and the rights stay with the original artists. This repo is just a personal collection.

If you're the owner of an artwork and want it credited or removed, open an issue and I'll take care of it right away.

## Notes

- Filenames like `wallhaven-xxxxxx` are the original Wallhaven IDs, so the source is easy to trace.
- Resolutions vary, mostly 1920x1080 and up.
